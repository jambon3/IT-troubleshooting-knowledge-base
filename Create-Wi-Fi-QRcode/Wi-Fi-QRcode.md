# Create a Wi‑Fi QR Code Using a Website

> **Note:** The Wi‑Fi details used in this example are **fictional** and provided for demonstration purposes only.

## Step 1: Open the QR Code Generator Website

Go to:

[QR Code Generator](https://www.qr-code-generator.com/)

## Step 2: Select WiFi

From the menu, select **WiFi** as the QR code type.

## Step 3: Enter the Wi‑Fi Information

Use the following example values:

| Setting | Value |
|----------|----------|
| Network Name (SSID) | `guest-wifi` |
| Password | `potato` |
| Encryption | `WPA/WPA2` |

> **Note:** These credentials are fictional and should be replaced with your organization's actual Wi‑Fi information.

## Step 4: Generate the QR Code

Click **Generate QR Code**.

## Step 5: Download the QR Code

Download the generated QR code as a **PNG** file.

## Result

Users can scan the QR code with their mobile device to automatically connect to the Wi‑Fi network without manually entering the network name and password.
