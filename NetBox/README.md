Our installation roadmap
1. Prepare Ubuntu
   
   Update packages and install required dependencies.
2. Install PostgreSQL
   
   Configure NetBox's database.
3. Install Redis
   
   Configure caching and background task support.
4. Install NetBox
   
   Download the application and configure it.
5. Configure application services
   
   Set up Gunicorn and systemd.
6. Configure Nginx and HTTPS
   
   Make NetBox accessible securely over the network.
